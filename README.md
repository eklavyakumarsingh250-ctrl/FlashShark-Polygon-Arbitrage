
# 🦈 FlashShark: Polygon Arbitrage Bot

**FlashShark** is a high-frequency arbitrage bot designed for the Polygon Mainnet. It leverages Aave Flash Loans to execute capital-efficient trades between decentralized exchanges (DEXs) like QuickSwap and SushiSwap.

## 🚀 Features
* **Zero-Collateral Trading:** Uses Aave Flash Loans to borrow capital instantly.
* **Dual-DEX Scanning:** Monitors price discrepancies between QuickSwap and SushiSwap.
* **Gas-Optimized:** Checks for profitability off-chain before executing on-chain transactions.
* **Mobile-Ready:** Fully optimized to run on Android via Termux.
